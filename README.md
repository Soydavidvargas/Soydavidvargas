## 👋 Hola, soy David

Este repositorio ha sido creado con el propósito de **organizar, almacenar y presentar las actividades, ejercicios, proyectos y evidencias desarrolladas durante mi formación en el programa de **Análisis y Desarrollo de Software (ADSO)** del **SENA**.

Aquí se irán recopilando los diferentes trabajos realizados durante el proceso de formación, permitiendo mantener un registro organizado de mi aprendizaje y evolución como desarrollador.

---

## 🎯 Propósito del repositorio

Este espacio está destinado principalmente a:

* 📁 Organizar las actividades realizadas durante la formación.
* 💻 Almacenar ejercicios y proyectos de programación.
* 📝 Presentar evidencias y trabajos solicitados por el instructor.
* 📚 Registrar el proceso de aprendizaje.
* 🔄 Mantener un historial de los avances realizados.
* 🚀 Aplicar los conocimientos adquiridos durante la formación.

---

## 📂 Organización

El repositorio se irá organizando de acuerdo con las diferentes actividades y proyectos desarrollados.

```text
📦 Repositorio
 ┣ 📂 Actividad-01
 ┣ 📂 Actividad-02
 ┣ 📂 Actividad-03
```

La estructura podrá modificarse conforme avance la formación y aumente la cantidad de actividades.
